# SimbolMap - Copie Pas Como

Varianta copiei cu toate repararile Pasul 1-4 + logo fara inscriptie + telefon alb + PUT pe poza + pin nu cerc.

## Poze - IMPORTANT
In `public/` trebuie sa pui pozele tale reale cu aceste nume exacte:
- `logo.png` - logo Simb + pin rosu + Map, FARA textul mic "Map of Feelings..." inauntru. Textul ala e in cod, sub logo, o singura data.
- `como.jpg` - poza mare Como (oras galben, lac, munti, cer auriu)
- `venice.jpg` - poza Venice
- `colosseum.jpg` - poza Colosseum
- Daca nu ai pozele, pune orice poza cu aceste nume, aplicatia va porni.

## Cum pui pe GitHub
1. github.com -> Your repositories -> simbolmap
2. Add file -> Upload files
3. Trage TOATE fisierele din folderul asta + folderul `public/` cu poze
4. Commit changes

## Cum verifici pe Vercel
1. vercel.com -> proiect simbolmap -> Deployments -> asteapta Ready
2. Deschide simbolmap.vercel.app in Chrome (nu din chat, nu din WhatsApp)
3. Daca arata ca copia, abia apoi legi domeniul simbolmap.com in Settings -> Domains

## Ce s-a reparat in copia asta
1. Logo click -> sus, click pe alt simbol -> sus, fara banner "X selected"
2. S si P nu taiate, slogan 1 rand: "The pulse of the place." negru + "Leave a feeling for someone." rosu
3. PUT pe poza, poza mare 480px desktop / 420px telefon, pin nu cerc, lacat standardizat
4. Telefon alb fortat, header nu acopera poza, stea aurie, Top feelings nu taiat, logo mare 56px, descriere nu pe granita
